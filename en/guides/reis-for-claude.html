reIS for Claude

Ask Claude about your timetable, exams, points or assignment deadlines. Claude reads them in MENDELU IS and answers. It works in Claude (the AI chat by Anthropic, similar to ChatGPT), not in ChatGPT.

First you need Claude Desktop on a Mac or Windows. A free Claude account is enough (it has a message limit). It does not work on a phone or in the browser. You get a .mcpb file, an extension that Claude Desktop opens. The source code is public.
Download reIS for Claude

3 steps

  1. Install Claude Desktop and sign in (free). Already have it? Skip.

  2. Download reIS for Claude and double-click it. If your browser hesitates over the file, choose Keep. Claude Desktop offers Install. Then enter your IS login (e.g. xnovak) and password.

    The password is stored in your system keychain (Keychain / Credential Manager) and is sent only to is.mendelu.cz. You can read the source code.

    Claude Desktop shows this red warning for every extension outside Anthropic's own catalogue; reIS for Claude only reads IS, and its code is public.

  3. Ask in a new chat, in English or Czech. When Claude asks whether it may use reIS, allow it.

What to ask

  • “How many points am I missing for the credit in Computer Networks?”Reads the Záznamník and the course rules and works it out.
  • “What’s my timetable tomorrow?”Times, rooms, who teaches.
  • “Which exams am I registered for, and which dates still have seats?”Dates, rooms, free seats.
  • “What do I have to hand in this week?”Assignments with deadlines.

Security

  • Read-only. It changes nothing in IS and never registers you for an exam.
  • Runs on your computer. The password goes only to MENDELU IS.
  • IS data go into your own Claude chat (to Anthropic, like any message) only when you ask. They never pass through reIS.
  • It checks GitHub for a new version. It does not update itself. Privacy policy
Not working?
  • Nothing happens on double-click: install Claude Desktop, or drag the file into Claude Desktop › Settings › Extensions.
  • Two-factor login (TOTP) on in IS: not supported yet.
  • New version: Claude tells you when it is out. Download the file again and open it.

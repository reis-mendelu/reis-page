reIS for Claude

Ask Claude about your timetable, exams, points or assignment deadlines. Claude reads them in MENDELU IS and answers.

Download reIS for Claude
You need Claude Desktop on a Mac or Windows. A free Claude account is enough. It does not work on a phone or in the browser.

3 steps

  1. Download the file with the button above.

  2. Double-click it. Claude Desktop offers Install. Then enter your IS username and password.

    The password is stored in your system keychain (Keychain / Credential Manager) and is sent only to MENDELU IS.

  3. Ask in a new chat, in English or Czech.

What to ask

  • “How many points am I missing for the credit in Computer Networks?”Reads the Záznamník and the course rules and works it out.
  • “What’s my timetable tomorrow?”Times, rooms, who teaches.
  • “Which exams am I registered for, and which dates still have seats?”Dates, rooms, free seats.
  • “What do I have to hand in this week?”Assignments with deadlines.

Security

  • Read-only. It changes nothing in IS and registers you for nothing.
  • Runs on your computer. The password goes only to MENDELU IS.
  • IS data go into your own Claude chat only when you ask. They never pass through reIS.
  • It checks GitHub for a new version. Privacy policy
Not working?
  • Nothing happens on double-click: install Claude Desktop and open the file again.
  • Two-factor login (TOTP) on in IS: not supported yet.
  • New version: Claude tells you when it is out. Download the file again and open it.

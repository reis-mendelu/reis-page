Data for student projects

Real MENDELU data for your course project, whatever the subject. One link, no key, no sign-up. Use it and credit “data from reIS”.

Get the data

Subject success rates17,459 rows, 2005–2025, all facultiesJSONCSV
Erasmus1,717 reports, 189 universities, 28 countriesJSONCSV

How to load it

Web (JavaScript), in the browser console:

const url = 'https://cdn.jsdelivr.net/gh/reis-mendelu/reis-data@main/student-data/success-rates.json';
const rows = await (await fetch(url)).json();
console.log(rows.filter(r => r.code === 'EBC-PJ'));

Python with pandas:

import pandas as pd
df = pd.read_csv('https://cdn.jsdelivr.net/gh/reis-mendelu/reis-data@main/student-data/success-rates.csv')
print(df[df.code == 'EBC-PJ'])

Java, with the file downloaded next to your project:

var lines = Files.readAllLines(Path.of("success-rates.csv"));
String[] p = lines.get(1).split(",");   // first row after the header

Some rows have a comma inside quotes, so a plain split sometimes breaks them. For the whole file use a CSV library, for example OpenCSV.

What is in the files

Success rates: one row is one subject in one semester.

  • code, nameCs, nameEn: subject code and name
  • facultyId: faculty in IS (PEF 2, AF 14, FRRMS 23, LDF 38, ZF 60, ICV 220)
  • semester, year: for example ZS 2025/2026 - PEF and 2025
  • kind: exam or credit
  • a to fn: number of grades A, B, C, D, E, F, FN
  • pass, fail: how many students passed and failed
{"code":"EBC-PJ","nameCs":"Programovací jazyk Java","facultyId":2,
 "semester":"ZS 2025/2026 - PEF","year":2025,"kind":"exam",
 "a":19,"b":12,"c":17,"d":13,"e":13,"f":4,"fn":1,"pass":74,"fail":5}

Erasmus: one row is one student report, numbers only.

  • hostUniversity, hostCountry: where the student went
  • stayFrom, stayMonths: start (YYYY-MM-DD) and length in months
  • accommodationPerDay, foodPerDay, transportCost, totalCostCZK: costs as the student wrote them
  • grantCoveragePercent: what percent of the cost the grant covered
  • recognized: true or false, whether the stay was recognised
  • rating: rating 1 to 5
{"hostUniversity":"FH Wien der WKW University of Applied Sciences for Management & Communication",
 "hostCountry":"Rakouská republika","stayFrom":"2024-02-05","stayMonths":4.9,
 "accommodationPerDay":13,"foodPerDay":10,"transportCost":2000,
 "totalCostCZK":80000,"grantCoveragePercent":80,"recognized":true,"rating":4}
Watch out for
  • Erasmus numbers are as the student wrote them. Units are not unified (accommodation sometimes shows a monthly price instead of a daily one) and a missing value is null. Cleaning the data is part of the project.
  • These are aggregated numbers. There are no names of students or teachers, so do not look for them.
  • No warranty. The statistics come from the MENDELU IS pages. If you use the data, credit “data from reIS”.
Where the data comes from

Success rates are the subject statistics in MENDELU IS. Erasmus numbers come from reports students handed in at MENDELU, without names, e-mails or free-text answers. The files and the script that builds them are public on GitHub.

eduroam at MENDELU: set up in 3 taps

To use eduroam, the university Wi-Fi, you need a personal certificate from UIS that is valid for one year. The reIS app fetches it and sets eduroam up for you. If you'd rather not use the app, the full official procedure is below.

Checked on 15 Nov 2026 against the official guides at eduroam.mendelu.cz. reIS is an independent student project, not an official MENDELU app.

With reIS: three taps instead of twenty steps

In the reIS app, open Profile › Eduroam and tap Set up eduroam. reIS fetches your certificate from UIS and hands it straight to your phone's system. Nothing to download, no password to copy, and no need for the faro-free network: any internet connection works, mobile data included.

iPhone and iPad

Three taps in the reIS app. eduroam stays set up for as long as reIS is installed.

Android

Three taps in the reIS app.

Mac

reIS prepares a ready eduroam profile and shows its password. You install it in System Settings › General › Device Management.

Windows

The reIS extension prepares a ready profile for the geteduroam app, shows the password and walks you through it.

reIS also warns you before the certificate expires, and a new one is a single button away. Your certificate goes nowhere else: reIS hands it straight to your device.

On a computer: the extension for Chrome and Edge or Firefox. On a Mac, also the reIS app from the App Store. Install guide

The official way, without reIS

This is the procedure the university describes at eduroam.mendelu.cz. It starts the same on every device:

  1. Connect to the faro-free Wi-Fi. It only reaches MENDELU websites, which is enough for IS.
  2. Log in at is.mendelu.cz.
  3. Open the eduroam certificate page (in Czech: Technologie a jejich správa › Certifikát bezdrátové sítě (eduroam)).
  4. Generate a new certificate and copy the password it shows. Every certificate has its own password.
  5. Download the user certificate and, depending on your device, the root certificate (see below).

iPhone and iPad (iOS 15 and later)

  1. Download the certificate in Safari. It does not work from Chrome or Firefox.
  2. Download the user certificate and open Settings › the downloaded profile. If it isn't offered, search Settings for "profile".
  3. Tap Install, enter your device passcode, then the certificate password from UIS.
  4. In Settings › Wi-Fi, forget faro-free and tap eduroam.
  5. Set Mode to EAP-TLS and Identity to the installed profile named login@mendelu.cz.
  6. Tap Trust. You'll be connected within a minute.

Source: official iOS 15 manual

Android (Android 13)

  1. In UIS, download the user certificate (type Wi-Fi certificate, with the password from UIS) and the root certificate.
  2. Open Settings, search for "certificate" and choose Install certificates. Your phone needs a screen lock.
  3. From Downloads, install the root certificate (.crt) first, then the user certificate (.p12) with the password from UIS. Add the year to its name so next year's doesn't get mixed up.
  4. In Wi-Fi settings, remove faro-free and tap eduroam.
  5. Method TLS, CA certificate your root certificate, domain mendelu.cz, user certificate the new one, identity login@mendelu.cz.
  6. Make sure there's no trailing space after the domain or identity. Pasting from the keyboard sometimes adds one.

The steps differ a little between phone makers and Android versions. If downloading or installing fails, give your browser storage permission, or install the certificate by hand in Settings › Security.

Source: official Android 13 manual

Windows 10 and 11

  1. In UIS, download and open the root certificate for MS Windows (root.der). Install it for the current user into Trusted Root Certification Authorities. You only do this once; it's valid until 2036.
  2. Download the user certificate for MS Windows, enter the password from UIS while installing, and choose the Personal store.
  3. Connect to eduroam. Windows usually configures the connection itself; otherwise choose Connect using a certificate.

Source: official Windows 11 manual, Windows 10

Mac (macOS Ventura and later)

  1. In UIS, download both the root and the user certificate (.p12), then open Keychain Access.
  2. Use File › Import Items to import both into the login keychain. For the user certificate, enter the password from UIS.
  3. Set both certificates to Always Trust.
  4. In Wi-Fi settings, choose eduroam and select the login@mendelu.cz certificate as the identity.
  5. Accept the server certificate aleph.mendelu.cz and enter your keychain password. If it doesn't connect the first time, close the error and try again.

Source: official macOS Ventura manual

eduroam not working: the usual causes

  • The certificate expired. It lasts 366 days and IS never renews it by itself. Generate and install a new one; see certificate validity.
  • Two certificates are installed. Keep only the valid one. Repeated attempts with an expired certificate can get your account blocked on the server.
  • Your iPhone won't download the certificate. Use Safari, not Chrome or Firefox.
  • Android asks for a domain. Enter mendelu.cz, with no trailing space.
  • Your phone says it can't join eduroam while you're off campus. That's fine: eduroam simply isn't in range. You'll connect on your own at the faculty.

If nothing helps, contact helpdesk.mendelu.cz. More answers are in the official FAQ.

Certificate validity and renewal

The eduroam certificate is valid for 366 days from when you generate it. IS never renews it and keeps offering the old one, so one day eduroam simply stops working. The university emails you when it's about to expire.

To renew: generate a new certificate in UIS, install it, and remove the old one from your device. Generating a new one does not revoke the old one, so you can renew early. reIS warns you on its own as the date approaches and a new one is a single button away.

Frequently asked questions

Is reIS an official MENDELU app?
No. reIS is built by MENDELU students in their free time. It takes the certificate straight from your UIS, just like the official procedure.
Where do my certificate and password go?
Nowhere. reIS fetches the certificate from UIS and hands it to your device's system. It is never sent to any reIS server. More on Data and security (Czech).
How much does reIS cost?
Nothing. The app and the extension are free.
Do I need the faro-free network?
Not with reIS: mobile data is enough. The official procedure uses faro-free to download the certificate from IS.
